# 桂圆潘尔赛的日常 · 银行大厅（Phaser 3）

第一个场景：银行职员「潘尔赛」可以在银行大厅里上下左右走动。

## 运行

```bash
npm start          # 启动零依赖静态服务器
# 然后打开 http://localhost:5173
```

必须通过 http 打开（浏览器不允许 `file://` 下加载 ES 模块和图片）。用
`python3 -m http.server 5173` 也可以。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` 或 方向键 |
| 快走 | 按住 `Shift` |
| 互动 / 翻对话 | `E` 或 `空格` |
| 显示碰撞体 | `B`（调场景时很有用） |
| 触屏 / 鼠标（电脑模式） | 按住拖动 = 虚拟摇杆 |
| 手机模式 | 左下方向盘移动，右下 `E` 互动 |

打开页面先看到**开场界面**：三个角色的卡通头像 + 必选的模式（电脑 / 手机）+ 开始游戏。
选电脑模式就是上面这套键盘操作；选手机模式会尽量切成横屏（`requestLandscape()`：先试
全屏再试 `screen.orientation.lock('landscape')`），转不过来时（iOS 之类）会盖一层
「请把手机横过来」的提示，进游戏后用左下方向盘 + 右下互动键。

黄姐一开始站在大厅左边的花盆旁边，先找她说话（说完她就加入队伍，之后会一直跟在
潘尔赛身后走）——**入队之后走到大门口那块就会自动出门**（没入队只会冒个气泡提醒）。
外面是一条横着的马路：
左边路牌「水星街道」，右边路牌「松鸭湖」（路牌只是画面装饰，不会挡路）——
走到马路**左边尽头**会自动触发"约了杨凡一起吃饭"的对话（说完潘尔赛回头朝右），
走到**右边尽头**会自动切到松鸭湖场景；两头整片尽头区域（人行道的上边、下边）
都能触发，也可以按 `E` 主动触发。
在街上**往上走到银行大门正下方**（人行道最上面那一块）会自动回到银行大厅。
两个门口都只在"刚踏进那块区域"的那一帧触发，所以进门后站在原地不会来回弹。

进松鸭湖时人从地图**最左边**的路口出来（朝着场景里站着）；杨凡站在上面靠近湖边
栏杆的红马路上等着，走过去按 `E` 就能聊：说完「那就去双季红吃火锅吧」，他就加入队伍、
跟在黄姐后面一起走（`registry` 里的 `yangJoined`）。最左边那块路牌写着「回银行路口」，
走到最左边（再往左一顶）就直接切回马路，不用按键；**右上角**的路牌写着「去双季红」，
走到右上角（x 够右、y 够靠上）就直接进火锅店。

进了双季红火锅店，走到中间那桌按 `E`：三个人各自走到桌后坐下（桌子画在人物前面，
正好挡住下半身），潘尔赛说「开吃开吃」，锅上开始冒热气；吃一会儿潘尔赛和黄姐一起
吐彩虹，最后潘尔赛喊「这是僵尸肉！！！」。看完这段他们站起来，又能自由走动了；
走到左边门口就回松鸭湖。

湖边整片地面都能走（`LAKE.walk`）：红色的湖边马路 + 靠里的灰褐色路面。
左上角是湖水，**岸边的栏杆就是边界**——`LAKE.shore` 里那几块看不见的"台阶"挡板
沿着栏杆那条斜线把水拦掉，数值是照着背景图逐行量出来的（每块一个 y 区间 + 陆地
左边界 x）；换背景图就重新量一遍。`LAKE.yang` 也在这条线附近，所以杨凡就站在
栏杆下边的红马路上。

交互按「潘尔赛正面朝向」判定：背对柜台时按 `E` 不会误触发身后的黄姐；
回头面对黄姐（或和她重叠）再按 `E` 才是和她说话；旁边有柜台、路牌这类交互物时，
它们的优先级高于黄姐。

## 人物素材是怎么来的

原始 `潘尔赛的人物精灵图.png` 是 6048×672、白底、9 个动作排成一行的图片，
直接切图会有三个问题：没有透明通道、每格人物位置有漂移、白边发灰。

`python3 tools/build_assets.py` 会（精灵表 + 头像一起处理）：

1. 从画布四边泛洪填充，把与边缘连通的白色背景抠成透明（人物身上的浅色
   衬衫是封闭区域，不会被误伤）；
2. 对贴着背景的浅灰像素做半透明过渡，消除白边；
3. 取所有帧的**公共包围盒**裁切，保证动画不抖动；
4. 缩小 2 倍输出 `assets/pan_ersai.png`（1791×317，单帧 199×317，580KB）；
5. 打印 ASCII 预览，方便在没有图形界面时肉眼检查抠图效果。

2048×2048 的两张卡通半身像也走同一套流程：去背景 → 定位头肩 → 以脸为中心裁成
圆形、加黄铜描边，输出 224×224 的对话头像。要调整头像取景，改 `process_portrait`
里的 `head_h`（脑袋占头肩高度的比例）和 `diameter`（取景直径倍数）即可。
个别素材框得比较远（杨凡那张脑袋偏小），可以在 `PORTRAITS` 里给它单独加
`diameterScale`（收窄取景）和 `centerShift`（取景中心上下左右挪一点）。

同一支脚本还负责 `BACKGROUNDS` 里的场景背景：松鸭湖那张原图右下角带着
「豆包AI生成」的水印，脚本会用**水印正上方同样花色的地面**把那一块盖掉、四周羽化
（这类 AI 背景的地面是低频近似纯色，搬一块过来看不出接缝），再缩到游戏里实际
显示的 1280×960 输出 `assets/lake_bg.png`。要加别的背景，在 `BACKGROUNDS` 里
追加一条、把水印位置写进 `watermarks` 即可。

换素材或改缩放倍数后，同步 `src/config.js` 里的 `SPRITE.frameWidth /
frameHeight` 即可。

## 关于朝向（重要）

原始精灵图的 9 帧其实是**4 组朝向的姿势**，不是一条步态循环——按 0→8 的顺序
播放会看起来像人物在原地转圈。用像素分析（脸部皮肤在头部的位置 + 剪影镜像匹配
+ 头部区域差异）可以确认：

| 帧 | 朝向 | 判断依据 |
| --- | --- | --- |
| 0、1 | 正面 | 脸在头部正中间，剪影左右对称度 0.94~0.96 |
| 4 | 背面 | 头部几乎没有皮肤像素，对称度 0.98 |
| 3、7 | 左侧面 | 脸贴在头部左边缘，且两帧头部差异极小（同一角度、不同步伐） |
| 6、8 | 右侧面 | 脸贴在头部右边缘，两帧头部接近、腿部不同 |
| 2、5 | 过渡角度 | 介于正/侧之间，用进动画会看出"转身"，已排除 |

所以现在按需求做了四方向：

| 输入 | 动画 | 画面 |
| --- | --- | --- |
| 上 | `pan-walk-up` | 背影 |
| 下 | `pan-walk-down` | 正面 |
| 左 | `pan-walk-left` | 左侧身 |
| 右 | `pan-walk-right` | 右侧身 |

另外两点手感处理：

- 停下来时保持最后的朝向（`pan-idle-*`），不会突然转回正面；
- 斜着走时按更"主导"的轴显示（左右优先），不会插入转身的中间帧。

背面素材只有一帧，所以向上走路用「单帧 + 步伐起伏」表现；其余方向都是两步循环。
换帧、加帧或改速度只改 `src/config.js` 里的 `SPRITE.directions`。

## 黄姐：朝向、对话与跟随

黄姐的走动素材同样是 9 帧一行（单帧 240×286），逐帧比对头部区域后分组：

| 帧 | 朝向 | 判断依据 |
| --- | --- | --- |
| 0、1 | 正面 | 脸在头部正中，能看到五官 |
| 2、4 | 右侧面 | 脸贴在头部右边缘，两帧头部差异只有 24（几乎同一角度）、腿部不同 |
| 5、8 | 左侧面 | 同上，脸贴左边缘，头部差异 30 |
| 3、6、7 | 过渡角度 | 介于正面和侧面之间，用进动画会看出"转头"，已排除 |

⚠️ 这组素材里**没有背影帧**，所以她向上走时暂时复用正面姿势。补一张背影图后，
改 `src/config.js` 里 `HUANG.directions.up` 的帧号即可。

对话与跟随的实现：

- 台词写在 `src/config.js` 的 `DIALOGUE` 里，格式是 `{ who, text }`，`who` 取
  `pan` / `huang`，对话框会自动换边显示并切换头像；按 `空格` 或 `E` 翻页，
  最后一句后触发 `joinTeam()`。
- 入队后黄姐会踩着潘尔赛经过的路线跟上来（面包屑轨迹）：场景每 5px 记一个点，
  她的目标是"沿轨迹往回数 78px"的那个点，所以拐弯也会跟着拐。
- 掉队超过 260px 会加速追（`catchUpSpeed`），卡住超过 2.5 秒会自动归队。
  这些参数都在 `HUANG.follow` 里。

## 杨凡：朝向与入队

杨凡的走动素材同样是 9 帧一行（单帧 180×321），逐帧比对头部区域后分组：

| 帧 | 朝向 | 判断依据 |
| --- | --- | --- |
| 0、1 | 正面 | 脸在正中，两只眼睛都能看到 |
| 2、7 | 左侧面 | 脸贴在左边缘、只露出一只眼睛，两帧头部几乎一致 |
| 4、5 | 更偏左的侧身 | 5 几乎看不到五官（这组里最像背影的一帧） |
| 3 | 接近正面 | 介于正面和左侧之间 |
| 8 | 右侧面 | 这组素材里唯一朝右的一帧 |

⚠️ 右向只有一张、也没有干净的背影帧，所以 `YANGFAN.directions` 里向右用单帧
（和潘尔赛向上一样的处理），向上暂用最"背过去"的 5 号帧；补图后改帧号即可。

入队走的是通用的「场景 NPC → 队友」通道：`setupCommon({ npcs: [...] })` 里的 NPC
带着 `onFinish` 钩子，对话翻到最后一页时调 `joinNpcTeam()`——原地解除实体碰撞、
挂上 `FollowTrail`、写 `registry.yangJoined`，弹一条「杨凡加入队伍」。之后进银行、
回街道、再来松鸭湖，他都会跟着（每个场景 `setupCommon` 里传 `yangX/yangY` 即可）。
为了不叠在一起，他的 `follow.distance` 是 150（黄姐 78），三个人自然排成一队。

## 双季红火锅店（一段小过场）

店里那几个动作是靠三个小机制拼出来的，都在 `HotpotScene` + `systems/effects.js` 里：

- **坐下**：桌子上沿画在人物**前面**（桌子的 `depth` 取桌脚 y=560，坐下的位置在 y=402），
  所以人走到桌后就被桌面挡住下半身，看起来就是坐着。三个座位写在 `HOTPOT.seats`，
  潘尔赛坐中间，黄姐和杨凡分两边。
- **过场**：`GameScene.setCinematic(true)` 之后玩家输入、跟随、互动全停，走位交给剧情
  自己 `tweens.add`（顺便播 `xxx-walk-down`），这时对话还能正常翻页。演完 `standUp()`
  把人挪回桌前再 `setCinematic(false)`。
- **冒热气 / 吐彩虹**：`potSteam()` 每隔 260ms 往锅里丢几团白色椭圆；`rainbowVomit()`
  从**嘴边**喷一串彩色小球（先往外再落下）。嘴的位置按角色不同写在
  `SPRITE/HUANG/YANGFAN.mouthRatio`（是从各自精灵图上量的：嘴离脚底占身高的比例），
  量法是沿脸部中线往下找那条深色的嘴线（潘尔赛 0.71 / 黄姐 0.73 / 杨凡 0.66）；
  喷之前还会再往下压 10px、只往上飘一点点——不然粒子会糊在鼻子或额头上。
  换角色素材时重新量一遍这个值就行。

## 背景音乐（BGM）

没有音频文件——`src/systems/bgm.js` 用 Web Audio **现场合成**了一段 8 小节循环
（约 16.6 秒，116 BPM，带摇摆的 16 分音符，C - Am - F - G7 - C - Am - D7 - G7）：
三角波 + 方波叠出来的"小玩具琴"主旋律（挂一点点延迟当卡通回声，每 4 小节末尾
来个下滑音当笑点）、一板一眼走路的贝斯、脚鼓 / 军鼓 / 沙锤。音色和谱子分别在
`PROGRESSION`、`playLead`、`playBass` 里，想换味道改这几处就行。

- 浏览器要求先有用户手势才出声，所以是**在开场界面第一次点屏幕时**启动的，
  之后一直循环、跨场景不断（模块级单例）。
- 右上角有 🔊 / 🔇 按钮随时静音，选择记在 `localStorage.bgmMuted` 里；
  切到后台会自动 `suspend()`，回到前台继续。
- 控制台可以直接调：`window.bgm.start() / .stop() / .mute() / .playing()`。

## 开场界面与手机模式

- 开场界面是 `StartScene`：三个角色的卡通头像（直接用 `assets/avatar_*.png`——
  从各自的卡通图裁出来的圆形头像，比塞 2048×2048 的原图小得多）、必选的模式、
  开始游戏按钮。选完写进 `registry.inputMode`，然后进银行大厅。
- 电脑模式：`GameScene.createControls()` 走原来那套（键盘 + 按住拖动的摇杆），
  操作逻辑一点没变。
- 手机模式：`createControls()` 改成 new 一个 `TouchControls`（左下方向盘 + 右下互动键），
  `readInput()` 读它的方向向量、`interactJustPressed()` 把右下按钮和 `E` / `空格`
  一视同仁；底部提示条会经 `mobileHint()` 把「WASD…」自动换成「左下方向键…」。
- 横屏：`requestLandscape()` 在"开始游戏"这个用户手势里尽量全屏 + 锁方向。
  如果浏览器吞了（微信 / QQ 内置浏览器、系统开了"竖屏锁定"，视口一直是竖的），
  `applyLayout()` 会给 `body` 加上 `forced-landscape`：把画布**自己转 90°**
  铺满屏幕——尺寸按视口算好、绝对定位居中，写在 `index.html` 的样式表里并用
  `!important` 压住 Phaser 每次 refresh 写进 canvas 的行内 `width/height/margin`。
  这样玩家把手机横过来就能玩，界面不会再缩成竖屏里的一条小横条。
- 自己转过 90° 之后，浏览器给的触摸坐标也是"转过"的，所以 `orientation.js` 顺手把
  `input.transformPointer` 反着算回去（屏幕左上 = 游戏左下，屏幕右上 = 游戏左上）；
  不转的时候完全不碰它，电脑模式一点不受影响。
- 竖屏视口下刚开始会闪一下「请把手机横过来」的提示（4 秒后淡掉，`pointer-events: none`
  不挡操作）。
- 结局画面按 `R` 回到开场界面重新选模式（`registry` 里的剧情进度一起清空）。

## 场景切换与街道

每个场景都继承 `src/scenes/GameScene.js`，它提供了所有场景都要用的东西：
共用素材、角色与阴影、HUD、键盘 + 触屏摇杆、对话推进、跟随、互动判定。
子类只要干三件事：画自己的背景、摆道具和碰撞体、给出交互点列表。

```js
this.setupCommon({
  playerX, playerY,          // 出生点
  huangX, huangY, huangJoined, // 黄姐的位置和是否已入队
  hint: '底部提示文案',
  interactables: [
    { x, y, radius, label, hint, action: () => {...} }, // 交互点
    { x, y, radius, label, line: '说一句话' },           // 或者只冒个气泡
  ],
});
```

切换场景就一条线：`this.scene.start('StreetScene', { from: 'bank' })`，
转场时先 `cameras.main.fadeOut()`，在新场景 `setupCommon()` 里统一 `fadeIn()`。
「黄姐是否入队」存在 `registry`（`huangJoined`）里，所以两个场景来回走，
她都会继续跟着；从街上回银行时，潘尔赛会站在大门口进来（`data.from === 'street'`）。

街道的横向分层写在 `STREET` 里（天空 / 建筑 / 人行道 / 路缘 / 马路 / 对面人行道），
可行走范围就是银行门口这一侧的人行道。两根路牌的文字是画贴图时直接
`ctx.fillText` 上去的，改 `STREET.signLeft.text` / `signRight.text` 即可。

## 关于场景美术

银行大厅是**用代码画的**（`src/art/bankArt.js`），没有使用
`银行场景设计.png`。好处是画面干净、分辨率无损、改配色只动几个数值，
而且柜台、ATM 的位置和碰撞体一一对应。参考图里的暖色大理石 + 深色木纹
+ 黄铜的配色被沿用下来。想换成自己的背景图，把 `BankScene.create()` 里的
`this.add.image(0, 0, 'bank-bg')` 换成加载自己的图片即可。
